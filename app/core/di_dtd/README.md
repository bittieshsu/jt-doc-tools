# 電子公文 DI 檔的 DTD（104 版，109 年 12 月修正）

公文撰擬匯出 DI 檔（文書本文檔）時，拿這幾個檔驗格式（`app/core/official_doc_di.py` 的 `validate()`）。

| 檔案 | 內容 |
|---|---|
| `104_2_utf8.dtd` | 函 |
| `104_5_utf8.dtd` | 簽 |
| `104_roster_utf8.dtd` | 交換表單（SW，企業的電子交換包會用到） |
| `104_basic_utf8.ent` | 基本標籤集 |
| `104_exchange_utf8.ent` | 電子交換標籤集 |

## 出處

國家發展委員會檔案管理局〈文書及檔案管理電腦化作業規範〉附錄 5「傳輸格式」。檔案取自「公文及檔案管理資訊系統驗證網」
下載專區的「文書及檔案管理電腦化作業規範(109年12月修正)之實作範例(11011更新)」
（<https://archives.cisanet.org.tw/download.php>，zip 的 sha256 開頭 `360264b5ae1ac349`），**內容一個位元組都沒改**（含 CRLF 行尾）。

這幾個檔是行政規則的附錄，依著作權法第 9 條第 1 項第 1 款不是著作權的標的，所以跟著程式放（不必像機關範本、地址簿那樣由管理員另外下載）。

## 改版時

規範改版（新的年度 DTD）時：換掉這幾個檔、改 `official_doc_di.DTD_FILES` 與 DOCTYPE，並重跑 `tests/test_official_doc_di.py`
（每個內建範例組出來的簽與函都要驗得過）。檔案管理局正在研議新的電子公文保存格式，到時候產生器只動 `official_doc_di.py` 這一支。
